# USER-20260814-MOVE-MEMORY — 無料の共通技管理「わざメモリー」を実装する

- Lane: `engine/content/ui/qa`
- Depends on: `USER-20260814-HM-FIELD-ACCESS`, `USER-20260814-BATTLE-RULES`
- Queue ID: `USER-20260814-MOVE-MEMORY`

## 目的

だいじなもの「わざメモリー」を追加し、既存NPCとitemの両方が同じ共通処理から、無料の
技思い出し・技忘れ・段階解禁したタマゴ技管理を行えるようにする。

## 完成仕様

- 1個目のバッジ後に「わざメモリー」を入手する。
- メニューは「わざを おもいだす／わざを わすれる／タマゴわざ／やめる」の4項目。
- 通常思い出しは現在種族の現在Lv以下、Lv.1、Lv.0進化時技、個別登録技だけを無料表示する。
- 通常プレイでは未来Lv技を表示しない。全Lv表示は最終クリア後の任意解禁だけにする。
- 技忘れは無料。最後の1技、タマゴ、戦闘/施設/Raid、一時form専用技は拒否する。
- PP Up適用技を忘れる前に警告する。HM field能力分離後はHM技も忘れられる。
- タマゴ技はD・Hビル後に解禁し、殿堂入り前はものまねハーブ所持＋空き技枠を要求、殿堂入り後は無料にする。
- シオウの技教えマニアとカラスバの技忘れオヤジは残し、キノコ消費を廃止して同じ共通処理を呼ぶ。

## 実装原則

1. NPC script全体をitemから呼ばず、会話/支払と技管理coreを分離する。
2. 保存flagを一時modeに流用せず、battle外RAMの `gMoveManagerMode` 相当で切り替える。
3. cancel、reset、画面遷移後にegg/all-level modeを残さない。
4. 技slotを直接代入せず `SetMonMoveSlot()` 系のCFRU共通関数を通す。
5. 進化前限定の重要技は、検証済みdata側のLv.1思い出し技で補う。

## 受入条件

- [x] item/NPC両入口が同じ候補と制限を返し、キノコを消費しない。
- [x] 通常Lv境界、進化時技、未来Lv拒否、egg解禁前後、殿堂入り後無料化がPASSする。
- [x] 最後の1技、PP Up警告、HM忘却、cancel/reset、form連動がPASSする。
- [x] バッグ・field・NPC会話へ正しく復帰し、battle/facility/Raid中は起動しない。
