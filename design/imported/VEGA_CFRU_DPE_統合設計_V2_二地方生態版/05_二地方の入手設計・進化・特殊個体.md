# 05 二地方の入手設計・進化・特殊個体

## 1. 「全ポケモンを両地方に出す」の定義

生態として自然にするため、**全1025種をそのまま両地方の草むらへ並べることはしない**。代わりに次を保証する。

- 541進化系統すべてに、トーホク側とカントー側の二つの入手導線がある。
- 通常系統は両地方で基礎種を捕獲できる。
- 進化後は育成で入手でき、カントー高レベルDexNavや殿堂入り後トーホクで中間進化を補助的に捕獲できる。
- 御三家は両研究所のタマゴ、化石は両研究拠点の復元で入手できる。
- 伝説・幻・UB・パラドックスは捕獲個体を一体に限定し、もう一方の地方には手掛かり・共鳴戦・素材報酬を置く。
- フォルム専用内部ID、戦闘中フォーム、メガ、キョダイ、テラ状態は通常野生個体として扱わない。

## 4. 進化条件のGBA向け変換

既存の `data/進化条件変換マスター.csv` を正本とし、次の原則を追加する。

- 通信交換：`つながりのヒモ`。
- 通信＋持ち物：持ち物を持たせて `つながりのヒモ`。
- 時間帯：昼夜機能を使うが、生態チケットで時間を固定できる。
- 歩数：歩数カウンタを保存し、ボード移動でも加算。
- 技使用回数：戦闘終了時に個体別カウンタを保存。
- マルチプレイ条件：NPCパートナーとのダブル調査または専用の証へ置換。
- Switch固有操作：道具使用、場所判定、手持ち条件へ変換。
- 取り返しのつかない二択：研究ポイントで再取得可能にする。

## 6. 特殊個体の共通安全仕様

1. 捕獲済みフラグを地方間で共有する。
2. 副地方へ先に到達した場合は手掛かりだけ取得し、捕獲イベントの場所を図鑑へ記録する。
3. 主地方で捕獲済みなら、副地方の固定戦は捕獲不可の共鳴体へ変わる。
4. 倒した場合は再戦キューへ入り、殿堂入り更新または研究所で復活。
5. 交換で図鑑登録済みでも捕獲イベントは消さず、「捕獲済みフラグ」でのみ分岐する。
6. PC満杯時は戦闘を開始せず、整理を促す。
7. 色違いロック、個体値、性格、持ち物、再戦レベルをイベントごとに明示する。
8. 全種を一つのROMで入手でき、外部配布・通信・期間限定を要求しない。
