# VEGA × CFRU-JP/DPE-JP 統合設計 V2 ― 二地方生態版

## 概要

このパッケージは、**ポケットモンスター ベガを本編の正本として残し、初回殿堂入り後にファイアレッド原作のカントー地方を追加し、トーホク・カントーの両方へ新世代ポケモンを配置する**ための実装仕様書です。

V1の「全国生態保護区中心」の案を改め、V2では次を設計の中心にしています。

- 公式全国図鑑No.1～1025を541進化系統として管理。
- 全541系統に、トーホク側とカントー側の双方の入手導線を設定。
- トーホクではベガ既存の野生表・1%枠・固有種・固定イベントを上書きせず、条件付きオーバーレイで新種を追加。
- カントーではFR原作らしい種を地域の顔として残しながら、高レベルの新種、DexNav、時間帯、大量発生を追加。
- 伝説・幻・UB・パラドックスは重複捕獲させず、主捕獲地方と副地方の手掛かり・共鳴イベントへ分担。
- FR原作のマップ形状、NPC座標、ジム内装、一部イベント演出を再利用し、フラグ・変数・トレーナー・報酬は統合版専用に作り直す。

## 推奨実装順

```text
1. ベガROMの既存ID・テーブル・SaveBlock・フックを抽出
2. 32MiB化と空き領域台帳の確定
3. DPE種族・技・特性・アイテムのIDマッピング
4. CFRUのSaveBlock、PC、図鑑、戦闘基盤
5. ベガ既存386枠とイベント個体の回帰試験
6. トーホク側の低率オーバーレイとT-E01～T-E16
7. カントーマップを新規マップグループへ複製
8. カントー野生、NPC、ジム、リーグ、イベント
9. 特殊個体の共有捕獲フラグと救済再戦
10. 全地方・全時間帯・全方法のQA
11. クリーンBPRJ Rev.0向け単一差分パッチを生成
```

## 重要な実装原則

- ベガIPSとファクトリーUPSを単純に順番適用しない。
- カントー原作マップをベガの元マップ番号へ上書きしない。
- トーホクの既存野生11枠や1%枠を新種と入れ替えない。
- 新種は追加抽選、時間帯、DexNav、釣り、水上、大量発生、固定イベントへ分散する。
- カントー認定章はベガのバッジフラグと分離する。
- 捕獲可能な固定個体には、撃破、逃走、手持ち満杯、PC満杯、セーブ／ロードの救済処理を入れる。
- 伝説・幻・UB・パラドックスは両地方で同じ捕獲済みフラグを共有する。
- 図鑑完成に通信、リアルタイム待ち、外部配布を要求しない。

これは**実装仕様書とデータ台帳**です。プレイ可能なROM、ROM本体、完成済み統合パッチではありません。実装時には、所有する正規ROMから作成したクリーンなBPRJ Rev.0を使用し、最終配布物は差分パッチのみとしてください。
