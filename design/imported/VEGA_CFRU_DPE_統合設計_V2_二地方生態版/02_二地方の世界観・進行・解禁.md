# 02 二地方の世界観・進行・解禁

## 1. 設定

追加種の存在は、別作品のストーリーをベガへ被せず、次の一本で説明する。

> D・H団がスフィア由来の波動と各地方の転送データを観測した結果、トーホクの生態境界が弱まり、従来確認されなかったポケモンが少数定着した。殿堂入り後、ヒイラギ研究所はオーキド研究所、シルフ、ニビ博物館と共同調査を開始する。

本編中の新種は「以前からいたが非常に少なかった個体」「D・H設備や海流に迷い込んだ個体」として扱う。伝説・UB・パラドックスだけは、スフィアいせきとカントー側の転送事故が起きるポストゲームまで出さない。

## 3. カントーへの移動

初回殿堂入り後、ヒイラギ研究所で `K-E01 二地方共同調査の出航` を開始する。

1. 全国図鑑と「カントーちょうさパス」を受け取る。
2. アーシア島または新設港から連絡船に乗る。
3. 船上の短いダブルバトルでカントー向けレベル帯を提示する。
4. クチバ港到着後、トーホクへいつでも戻れる。
5. カントーの8ジムはベガのバッジではなく「認定章」を授与する。
6. 認定章は通行、施設、野生表、ジム再戦にだけ使い、秘伝技・命令レベル・ベガ本編フラグには接続しない。

## 4. 研究ランク

| ランク | 条件例 | 解禁 |
| --- | --- | --- |
| 0 | バッジ1またはT-E01完了 | 基本DexNav、追加抽選、二地方図鑑表示 |
| 1 | 新種30種捕獲＋調査3件 | 大量発生、追加ボール、夜間固定チケット |
| 2 | 新種100種捕獲＋調査10件 | 隠れ特性、進化道具店、カントーサファリ更新 |
| 3 | 新種250種捕獲＋カントー認定章4個 | 化石全種、御三家タマゴ再取得、特性カプセル |
| 4 | 新種500種捕獲＋カントーリーグ | UB・幻の大半、特性パッチ、レイド高難度 |
| 5 | 新種800種捕獲＋スフィア遺跡＋二地方共鳴 | パラドックス、テラパゴス、最終図鑑報酬 |

捕獲数だけでランクを上げると作業感が強くなるため、固定イベント、進化、孵化、DexNav、サファリ、レイドをポイント化する。片方の地方だけを集中的に遊んでもランク3までは到達でき、最終ランクだけ二地方の主要イベントを要求する。

## 5. 両地方を回る意味

### トーホク側の利点

- 新種を低レベルから育てられる。
- ベガ本編のジム・D・H団・四天王へ新種を連れて行ける。
- 地形に沿った固定イベントで進化素材を早めに得られる。
- 殿堂入り後の既存拡張エリアへ新しい調査理由が生まれる。

### カントー側の利点

- Lv.68～100の即戦力を捕獲できる。
- DexNavで隠れ特性、タマゴ技、高個体値を狙える。
- 進化道具、ミント、メガストーン、テラピースを認定章報酬と施設で入手できる。
- FR原作の施設やイベント構造が、新世代要素のチュートリアルとして機能する。

## 6. 取り逃し防止

- 通常系統は両地方のどちらか一方だけで進化系統を完成できる。
- 片方の出現イベントを逃しても、もう片方の野生、DexNav、タマゴ、復元、研究交換で補える。
- 夜限定種は生態チケットで時間帯を固定できる。
- 大量発生はRTCだけに依存せず、歩数または殿堂入り更新でも切り替えられる。
- 固定個体を倒した場合、ヒイラギ研究所またはシオンの救済NPCで再戦登録する。
- 交換進化は「つながりのヒモ」、特殊操作進化は回数・場所・道具へ変換する。

## 7. 既存ベガポストゲームとの関係

カントーは既存のエリア調査、三島、スフィアいせき、ミラージュバトルを置き換えない。初回殿堂入り後に並行して選べる別ルートとする。

```text
殿堂入り後
  ├─ ベガ既存エリア調査
  ├─ トーホク全国生態保護区
  ├─ カントー認定章巡り
  └─ ミラージュ／ファクトリー
          ↓
いずれも進めると二地方共鳴編へ収束
```
