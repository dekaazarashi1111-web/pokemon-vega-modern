# VEGA × CFRU-JP/DPE-JP 統合設計パッケージ

作成日: 2026-08-12  
対象: `18年2月23日完成版ベガ(2).ips` と `factory_test_20260524(2).ups`

## 結論

二つのパッチを順番に当てる方式は採用しない。ベガを唯一のストーリー／マップ／イベント母体とし、DPE-JPの種族データとCFRU-JPの機能を、ID・フック・SaveBlockを再設計して移植する。

本パッケージは、そのための実装仕様、全1025種の入手方針、全541進化系統の配置、進化条件変換、フォーム対応、主要アイテム入手、伝説イベント、競合分析、QA計画をまとめたもの。プレイ可能な統合パッチそのものではない。

## 重要な使い方

1. CSVを正本にし、Markdownは方針説明とする。
2. 既存ベガ386枠の内部IDは、実ROMから抽出して `actual_internal_id` を埋めるまで変更しない。
3. 全国図鑑番号と内部種族IDを同一視しない。
4. 既存野生11枠を直接大量に置換せず、図鑑ナビ・大量発生・時間帯・生態保護区の追加レイヤーを使う。
5. トーホク図鑑386種の完成条件はそのまま。全国研究図鑑1025種は別の長期目標にする。
