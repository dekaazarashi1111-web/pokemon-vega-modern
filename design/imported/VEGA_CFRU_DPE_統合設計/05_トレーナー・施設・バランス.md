# 05 トレーナー・施設・バランス

## 1. 本編初回戦はベガを正とする

ベガは高難度を前提に、固有種と既存種の役割、技構成、レベル曲線が組まれている。CFRUの現代AIや技仕様を入れるだけでも実質的に難化するため、初回本編では次を守る。

- トレーナーの種族、レベル、個体数は原則維持。
- 無効化された技、特性、道具だけ置換。
- 現代化で威力・命中・タイプが変わる技は全件監査。
- AIランクを一般トレーナー、エリート、ジム、幹部、四天王の5段階に分ける。
- 序盤AIには交代読み、確定数計算、ギミック使用を許可しない。
- 初回リーグではダイマックス・テラを使わせない。

## 2. 追加種の使用先

| 使用先 | 追加方針 |
|---|---|
| 一般トレーナー初回 | 原則追加しない。調査員のみ新種を使用 |
| D・H団 | 人工、はがね、でんき、どく、あく系を少数追加 |
| ジム初回 | 既存チーム保持。切り札のメガはバッジ6以降でも最大1人 |
| ジム再戦 | 各タイプの第4～9世代種を全面採用 |
| 四天王再戦 | 6体、持ち物、隠れ特性、1ギミック |
| ミラージュ | 全国図鑑全種、レンタル、ルール別 |
| レイド | ダイマックス専用、捕獲・素材導線 |
| 生態調査員 | 新種の使い方を示すチュートリアル戦 |

## 3. ジム再戦コンセプト

- アヤメ：序盤鳥・虫から、追い風／飛行複合の全国編成へ
- ミル：耐久・回復・状態異常の現代化
- シオウ：雨・水上生態・フォルム活用
- ヒスイ：化石・古代種・砂嵐
- オウニ：雪・氷・鋼、オーロラベール
- カラスバ：悪・霊・メガ、読み合い
- ラピスラ：技範囲・フェアリー・テラの練習
- ニューアイランド：宇宙・ドラゴン・エスパー、最終総合戦

固有種を全て公式種に置換せず、最低2体はベガ固有種を残す。統合版の主役はあくまでベガである。

## 4. レベルと経験値

- 初回本編は固定レベル。
- 外来野生は同マップの既存中央値±2。
- DexNav連鎖でレベルが上がっても、その時点のバッジ上限を超えない。
- 殿堂入り後はバッジ数ではなく研究ランク・最高手持ちに応じてレイドだけスケール。
- 全体経験値共有はオン／オフ可能。オン時の経験値量は過剰育成を避ける係数を設定。

## 5. 種族値・技・特性

### 公式種

原則としてDPE-JPの第9世代基準を採用。ただし、ファクトリーパッチ側に独自の全種族値調整が含まれる可能性があるため、DPEソースの値を正本として差分を確認する。

### ベガ固有種

既存種族値・タイプ・特性・固有技を保持し、現代環境で役割が消える個体だけ最小調整する。調整は次の順序。

1. 技の物理特殊分類とタイプ一致を修正
2. 特性を現代効果へ接続
3. 習得技を補強
4. それでも不足する場合のみ種族値を±10～20調整

## 6. バトル施設

ミラージュバトルを次のモードへ拡張する。

- ベガクラシック：固有種中心、メガ等なし
- 全国シングル／ダブル：全国種、1ギミック
- レンタルファクトリー：ファクトリーパッチの主題を継承
- レイドシミュレータ：素材稼ぎ
- 逆さ／空中／天候固定：CFRU特殊ルール
- ボスラッシュ：ジム再戦・D・H幹部・四天王

## 7. 難易度設定

新規ゲーム時に三段階を選ぶが、マップ・ストーリーは共通。

| 難度 | AI | 持ち物 | ギミック | レベル補正 |
|---|---|---|---|---|
| スタンダード | ベガ相当 | ボス中心 | 終盤のみ | 0 |
| ベテラン | 交代・積み判断強化 | 幹部以上 | 終盤・再戦 | +1～2 |
| ファクトリー | 高AI | 主要戦全員 | 解禁後積極使用 | +2～4 |

難度で入手可能種、イベント、図鑑完成条件を変えない。
