# 受領設計パッケージ

## 現行の優先資料

`VEGA_CFRU_DPE_統合設計_V2_二地方生態版/` を、トーホク＋カントー二地方の完成像・進行・生態・イベント設計に関するactive review資料とする。

V2も `design-specification-only` であり、CSVをそのまま実装正本にはしない。`design/import_review.md` の既知課題を解消し、T12のschema・validatorを通したデータだけを `manifests/` / `content/` へ昇格する。

## 旧版

`VEGA_CFRU_DPE_統合設計/` はV1受領時点の来歴保存用であり、新規の実装判断には使わない。比較またはV2の来歴確認が必要な場合だけ参照する。

両ディレクトリの中身は受領時点のhashを保つ不変資料なので直接編集しない。
