# VEGA × CFRU-JP/DPE-JP 技調整設計 V3

このパッケージは、ベガ2018年2月23日完成版を母体とし、DPE-JP/CFRU-JPの第9世代対応環境へ統合するための**技習得・技効果・TM・教え技・野生初期技の設計台帳**です。

## 収録規模

- 公式ポケモン: 1025種
- ベガ／AS系オリジナル: 181種
- 合計: 1206種
- 公式進化系統: 541系統
- 技効果現代化: 61技
- ベガ／AS独自技再調整: 70技
- TM・教え技枠: 184枠
- 野生初期4技監査: 1206種
- フォーム継承方針: 509フォーム

## 重要な読み方

`review_confidence` は設計案の確度です。

- **A**: 専用技・特殊仕様・ベガ主要種など、個別方針を手動で設定。
- **B / B-**: タイプ、進化段階、世代、役割ルールから生成し、全件の整合性を機械検査。
- **C相当の注意**: 最終統合ROMから既存習得表を抽出しないと「削除すべき既存技の正確な差分」は確定しない項目。

この成果物は完成ROMへのバイナリパッチではありません。`Learnsets.c`、ベガ既存習得表、統合技ID、TM互換表を確定した後に適用する設計データです。

## 採用原則

1. 公式技の効果はCFRUの現代仕様へ統一。
2. ベガTM01～50の番号・イベント・報酬を保護。
3. TM51～120を現代技へ割当て、強い技ほど後期解禁。
4. ベガ独自技は削除せず、過剰な追加効果率・ダブル性能だけを調整。
5. 1系統に追加するレベル技は通常1～4個。広範囲サブウェポンはTM／教え技へ。
6. 野生の直近4技には命中90以上のSTABを最低1つ確保。
7. 戦闘専用フォーム・メガ・キョダイマックスは基礎種の習得表を共有。
8. 専用技は進化時／Lv1思い出しへ置き、通常TMにはしない。

## 実装順

1. 統合技ID台帳を確定。
2. ベガTM01～50を固定。
3. 公式技効果をCFRU現代仕様へ統一。
4. ベガ独自技の効果とAI評価を実装。
5. 公式541系統のレベル技を差し替え。
6. ベガ固有181種を手動差分確認。
7. TM／教え技互換を生成。
8. 野生初期4技、ボス合法技、施設レンタル技を検査。
9. 全ストーリー進行で取得時期を回帰試験。
