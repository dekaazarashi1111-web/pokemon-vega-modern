# 登録UI文字境界の限定型証明

## 対象と既存受入

親は `c2059ee805d978575b319e7a113b3edf0a676f1e` の登録state batch、776分類・98未知である。既存874件のidentity、全25段157changes/147witness、133曲/50asset、115実ownerを保持する。旧受入を変更せず、新しい独立登録根から残参照を分類する。

新しい候補はFrontier記録の `0914100D` と、ChooseMove表示の `09143266`・`09143415`。新registryは3件・最小各4byte/計12byteで閉じ、現候補測定で一致した場合だけ779分類/95未知へ更新する。測定結果・run・source・証跡の正本は専用checkpointとする。

## 証明の深さ

- 公開固定source、登録pointer/call、文字serializer、全選択caller命令、consumerのEOSを含む全文読取を結ぶ。
- Frontierはspecial057の実slotからtask/main callback登録、state producer、WindowPrintと実printerを結ぶ。内部stateをhostで直接選んで登録根を代用しない。
- ChooseMoveは0802E1ECの実公開hookから現QoL/BattleUI wrapper・正規prologueを通し、key分岐と実effect tableを経てprinterまたはStringCopy読取へ到達する。
- 各opaque calleeの正常ABI復帰と必要resource/戻り値だけを有限条件とする。実read-before-writeによるfuture-live RAM/stackのみ保持し、非liveを消去して同じ実path・消費を再現する。
- source、登録root、命令、field、文字、slot/epochを変えた場合は、証拠を再封印しても拒否する。
- 最小型は対象hitを覆う必要範囲だけとし、隣接text/関数/asset全域へ拡張しない。

以上は有限の型契約であり、自然入力からの全prefix到達、全calleeの効果、全UI描画完走、普遍的なIRQ・heap寿命の証明ではない。

## 測定と公開

旧06c5の有限窓による開発診断と、現0641の専用Actions測定を分離する。現候補の全identityを確認してから新consumerだけを検証し、既受入のnative・旧unit suite・旧全ROM走査は再実行しない。

公開は指定した有限text成果だけ。producer・公開guard・uploadの専用directoryとfilename契約を一致させ、非空size・LF・SHA・実Git blobと全5固定snapshotを確認する。失敗時に成功証拠を生成せず、原本と実失敗履歴を保持する。

## 変えない境界と次工程

現0641・正式ROM/Save101・115実owner/52保存owner・残804byteは不変。旧egg15118byteは全域保護し、安全容量0、donor未lease。間接参照完全性、退役、owner移管が閉じるまで容量へ昇格しない。

単一controller6528は未配線。heap13352はstock保存退避53300を跨がない。全保存入口のheap-ready・同期非再入・0804B85C退避前Freeを別gateで閉じてから、全S61E/MDX writer/loader/Link exact-source/no-main/INITIAL/全mode/早期31/species9bitへ接続する。

最終図鑑修復の正式切替後、trainer131後半からシオウで通常回復・保存・独立coldContinueを検証する。雑魚戦ごとのcheckpoint保存はしない。

旧拒否済み最終source reviewは未実施を保持し、同じ操作の別経路再試行は行わない。新UI scopeのsource reviewだけを独立に実施する。

## 固定した新consumer仕様

- Frontier: 公開19source、62保護窓2,423byte。実3,193命令/131境界でCurrent10byte+Max5byteをEOS込みで読む。task/mainの実writer-reader、state0→7の実producerを省略しない。不要な退役task/最後のprinter epochは要求しない。
- ChooseMove: 公開27source名、102保護窓2,214byte。NoContact/ResetStats/MaxHeal/MaxSpiteの4caseで全57byte/EOSを読む。公開move enum・manifest・producerから実effect fieldへ結ぶ。
- 統合source manifestは46local名/40固有の固定repository-ref-path。共通実sourceは同一全文identityを確認して再利用する。
- 新consumerの独立source-only検証と現0641全文fixtureの正式測定を区別する。疎fixture専用の閉包試験はtest内の独立Sparseを使い、注入した全文ROMに未指定範囲の欠落を要求しない。

## 次に必要なsource対応

残件のsource-only調査では083DDEE1/083DE02B/083DE6ABに新しい独立根を得ていない。再開には固定JP symbol出力または生成crosswalkから、いずれか1件の両側text symbol・EOS込みextent・実literal/table cell・API/callback登録を先に結ぶ。英語文字列の順番や近傍addressで所属を推測しない。独立対応がなければ未知を保持し、同じheld窓や旧suiteを反復しない。
