# クリア後カントー移植ポリシー

## 既定仕様

- カントーはVegaクリア後に解禁する別地方。
- 初期入口はクチバ港。
- 地方間移動は船または専用ターミナル。
- 初期実装ではカントー独自の8バッジ表示を作らず、ジム撃破フラグで進行する。
- カントー本土を優先し、ナナシマは後続scopeとする。

## 残すもの

- 地形と建物配置
- マップ接続の大枠
- NPC座標とグラフィック
- 一般NPCの雰囲気
- ジム内部構造
- ジムの仕掛け
- 一部の局所イベント

## 再定義するもの

- Map ID / Map group
- Trainer ID
- Species / level / moves / held item / AI
- Item IDと取得flag
- Script flag / var
- ジム撃破flagと報酬
- ワープ先
- ストーリー依存イベント
- 地方解禁条件

## 原作から原則そのまま持ち込まないもの

- 御三家選択
- オーキドに連れ戻される導入
- 図鑑受取
- おとどけもの
- 原作ライバル進行
- 原作ロケット団の全体flag体系
- 原作殿堂入り/エンディング
- ナナシマ解禁条件

## Namespace

```text
MAP_KANTO_*
FLAG_KANTO_*
VAR_KANTO_*
TRAINER_KANTO_*
ITEMFLAG_KANTO_*
SCRIPT_KANTO_*
```

## 最初の縦切り

```text
Vega地方の港
  -> クチバ港
  -> クチバシティ
  -> 一般NPC
  -> クチバジム仕掛け
  -> ジムトレーナー
  -> マチス相当ボス
  -> 新報酬
  -> Vega地方へ帰還
```

これで地方間移動、Map ID、NPC、スクリプト、トレーナー、報酬、セーブを一度に検証します。
